5. SERIAL COMMUNICATION
═══════════════════════════════════════════════════════════════

After programming, connect to serial terminal:

Using minicom (Linux):
  $ minicom -D /dev/ttyUSB0 -b 115200
  
  Settings: 8N1 (8 data bits, No parity, 1 stop bit)

Using screen (Linux/macOS):
  $ screen /dev/ttyUSB0 115200
  
  Exit: Ctrl+A, then type 'quit'

Using PuTTY (Windows):
  1. Set COM port (e.g., COM3)
  2. Set speed to 115200
  3. Connection type: Serial
  4. Click Open

Commands in serial terminal:
  1-4     Toggle LEDs (D12-D15)
  A       Turn ALL LEDs ON
  O       Turn ALL LEDs OFF
  S       Show Status
  H       Show Help menu

6. CODE EXAMPLES
═══════════════════════════════════════════════════════════════

GPIO Example:
  
  #include "gpio.hpp"
  using namespace stm32f407;
  
  // Create GPIO port instance
  GPIO gpio(GPIOPort::GPIOD);
  
  // Initialize pin as output
  gpio.init(GPIOPin::PIN12, GPIOMode::OUTPUT, GPIOSpeed::HIGH);
  
  // Control pin
  gpio.writePin(GPIOPin::PIN12, true);      // Set HIGH
  gpio.writePin(GPIOPin::PIN12, false);     // Set LOW
  gpio.togglePin(GPIOPin::PIN12);           // Toggle
  bool state = gpio.readPin(GPIOPin::PIN12); // Read


UART Example:
  
  #include "uart.hpp"
  using namespace stm32f407;
  
  // Create UART instance
  UART uart(UARTPort::UART2);
  
  // Initialize at 115200 baud
  uart.init(115200, UARTDataBits::BITS_8, 
            UARTStopBits::STOP_BITS_1, 
            UARTParity::NO_PARITY);
  
  // Send data
  uart.sendByte('X');
  uart.sendString("Hello STM32!\r\n");
  
  // Receive data
  if (uart.isDataAvailable()) {
      uint8_t byte = uart.receiveByte();
  }


Combined Example (from main.cpp):
  
  GPIO led(GPIOPort::GPIOD);
  led.init(GPIOPin::PIN12, GPIOMode::OUTPUT);
  
  UART serial(UARTPort::UART2);
  serial.init(115200);
  
  serial.sendString("LED System Ready\r\n");
  
  while (true) {
      if (serial.isDataAvailable()) {
          uint8_t cmd = serial.receiveByte();
          if (cmd == '1') {
              led.togglePin(GPIOPin::PIN12);
              serial.sendString("LED Toggled\r\n");
          }
      }
  }

8. FILE DESCRIPTIONS
═══════════════════════════════════════════════════════════════

gpio.hpp / gpio.cpp
  - GPIO port and pin control
  - Pin initialization with mode, speed, pull configuration
  - Read/write individual pins and full ports
  - Alternate function configuration for peripherals

uart.hpp / uart.cpp
  - UART/USART communication driver
  - 115200 baud (adjustable) serial communication
  - Blocking send/receive operations
  - Automatic GPIO pin configuration for TX/RX

stm32f407_registers.hpp
  - STM32F407 memory map and register definitions
  - RCC (Reset & Clock Control) registers
  - GPIO register structure
  - UART register structure
  - Hardware-specific constants and bit masks

startup.hpp
  - System clock initialization code
  - Reset handler and exception vectors
  - BSS/data section initialization
  - Can be used as reference for complete startup code

main.cpp
  - Complete working application example
  - LED control on GPIOD (pins 12-15)
  - Button input on GPIOA (pin 0)
  - UART serial interface at 115200 baud
  - Interactive command interpreter

11. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Build fails with "command not found":
  → Install ARM toolchain (see Prerequisites)
  → Verify PATH includes toolchain bin directory

Device not detected by STLink:
  → Check USB connection
  → Run: st-info --probe
  → May need udev rules on Linux: check ST website

Serial communication not working:
  → Verify baud rate: 115200
  → Check TX/RX pins are configured correctly
  → Verify UART clock is enabled in RCC

No LED response:
  → Verify GPIO port clock is enabled
  → Check pin definitions match your board
  → Use GDB to step through initialization code
